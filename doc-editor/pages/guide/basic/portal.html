自由节点
Portal 组件可以让其子节点脱离当前组件位置，并通过设置 host 属性的方式，渲染到我们指定的任何 DOM 节点中。如：当我们需要创建一个模态框时，我们更希望把弹窗渲染到 body 中，这时，我们可以 Portal 组件来帮我们完成。
import { Portal } from '@viewfly/core'

function App() {
  return () => {
    return (
      <div>
        <div>这里是普通内容</div>
        <Portal host={document.body}>
          <div class="modal">这里的内容会渲染到 body 中</div>
        </Portal>
      </div>
    )
  }
}
